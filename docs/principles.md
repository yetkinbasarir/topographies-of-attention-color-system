# Principles

## 1. System structure
The system has two linked layers:
- topographies
- attention

Topographies define field, climate, and surface.
Attention defines signal, focus, and active presence.

## 2. Day / Night
Colors never change between day and night.
No color is added, removed, lightened, or darkened.

Night mode is built only by reassigning roles inside the same monthly color set.

## 3. Monthly core
Each month contains:
- topography
- darkInk
- midInk
- attention

## 4. Day mapping
- background = topography
- primaryText = darkInk
- secondaryText = midInk
- line = attention
- attention = attention

## 5. Night mapping
- background = darkInk
- primaryText = topography
- secondaryText = midInk
- line = attention
- attention = attention

## 6. Shell references
The page shell does not use arbitrary neutrals.

It uses defined reference sets:

### Day Reference
- paper
- ink
- quietInk

### Night Reference
- paper
- ink
- quietInk
